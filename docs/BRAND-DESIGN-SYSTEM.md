# BRAND DESIGN SYSTEM — ALAMINN.INFO

Reference of the design system **as implemented** (verified in source, 2026-09-30). Improve consistently; do not introduce an unrelated theme.

## Brand identity

- **Owner:** Al Aminn — positioning: *"Executive Operations Leader, Sales Strategist, Education-Business Growth Specialist and AI-Powered Systems Builder"* (`src/lib/site-data.ts → PROFILE`).
- **Voice:** professional, confident, evidence-governed. Qualitative claims only; no fabricated metrics. The copy system marks verified vs. operating context ("Verified operating context", "No fabricated metrics").
- **Brand families:** ALO Education, ALO Labs, ICLA Global Academy (in content), BDTech360/Tech360 (`/ecosystem/*`) — connected but distinct.

## Colour tokens

Core palette (defined as CSS custom properties in `src/app/globals.css`, Tailwind 4 `@theme`):

| Token | Light | Dark | Use |
|---|---|---|---|
| `--primary` | `#F26113` (brand orange) | adjusted | Primary actions, accents |
| `--brand-blue` / links | `#0B63CE` | adjusted | Secondary accents, links |
| `--background` / `--foreground` | near-white / near-black | inverted | Surfaces |
| Card, muted, border, ring | derived neutrals | derived | Components |

Dark + light themes via `next-themes` (`ThemeProvider` in `src/app/layout.tsx`). All interactive elements must keep accessible contrast in BOTH themes.

## Typography

Self-hosted since 2026-09-30 (`src/fonts/`, OFL licenses included; wired via `next/font/local` in `src/app/layout.tsx`):

| Family | Variable | Role |
|---|---|---|
| Manrope (200–800 variable) | `--font-manrope` | Display/headlines — **preloaded** (LCP-critical) |
| Inter (100–900 variable) | `--font-inter` | Body text |
| DM Serif Display (400) | `--font-dm-serif` | Editorial serif accents |

Utility classes: `.font-display`, `.font-body`, `.font-serif` (`globals.css`). Never load Google Fonts at runtime.

## Component conventions

- **UI primitives:** shadcn/ui (`src/components/ui/*` — buttons, cards, dialogs, forms, tables, toasts via Radix + CVA).
- **Site sections:** `src/components/site/sections/*` (32 composable sections: hero, editorial-hero, expertise, ecosystem, social-hub, newsletter, contact-finale, photo-gallery, journey-timeline, testimonials, verification, …) + `section-primitives.tsx` for shared layout rhythm.
- **Motion:** `framer-motion`, subtle transitions, `prefers-reduced-motion` respected.
- **Buttons:** consistent CVA variants; primary = orange, secondary = outline; CTAs use real routes (never `#` dead links).
- **Images:** `next/image` with AVIF/WebP (`public/brand/portrait.{avif,webp,jpg,png}`), blur placeholders generated by `npm run images:blur`.

## Layout & responsiveness

- Mobile-first; consistent spacing scale; `container` pattern with stable gutters.
- Higher Study platform uses its own compact header (`src/components/higher-study/`) — logo returns to `/`.
- Accessibility: semantic landmarks, keyboard-navigable nav/drawers, focus-visible rings, labelled forms.

## Content rules

1. English/Bangla copy allowed; keep proper names and official university names untranslated.
2. Every statistic shown publicly must trace to the database or a verified source.
3. Portraits/imagery: only approved photographs from `public/brand/` and `public/gallery/`.
